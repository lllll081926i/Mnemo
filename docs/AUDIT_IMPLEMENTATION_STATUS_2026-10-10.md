## 验收条件与边界

### 2026-10-14 本地复核修正

- 修复重新授权后失效标记残留，以及重启后未恢复认证状态的问题；普通刷新保留网络和容量诊断。
- HTTP(S) 离线展示 URL 不再保留查询参数，避免 `sig` 或未知签名字段绕过关键字黑名单。原始提交 URL 不变，磁力资源标识不变。
- 清理上传历史先固定未运行的完成任务 ID，再持久化删除，成功后删除内存记录。收尾中的工作任务、失败及暂停记录均保留。`ClearUploads` 的 Promise 在持久化失败时拒绝，前端现有错误提示接收该错误。
- 补充账号重启/重新授权、收尾任务清理、持久化失败、嵌套迁移冲突回归；更新旧的“失效账号已移除”断言。
- 本地 `go test ./...`、`go test -race ./...`、`go vet ./...`、`go build ./...` 通过；前端 244 项测试及生产构建通过，保留既有大分块警告。云端状态以当前提交的 Actions 结果为准。
- 既有依赖审计另发现 Vue/server-renderer 与 source-map-js 安全公告，依赖锁不属于本 PR 改动；未宣称依赖零漏洞，需另行兼容补丁升级。真实网盘写入、长传输空闲超时及旧离线记录迁移仍不属于已完成验收。

1. **静态与模拟验证**：GitHub Actions 的 Go format、单元/集成/竞态测试、go vet、后端编译、Vue 测试与构建。**最新 CI 结果以工作流实际页面为准，不将排队视为通过**。
2. **网盘写入**：必须在测试账号或专用测试目录，先快照后写入。光鸭的云离线、PikPak 的收藏/秒传/覆盖、OneDrive 的个人恢复/企业 beta 均不得由 mock 推断真实服务端可用。
3. **优先级**：先解决 B-09/B-10/B-12/B-15、M06/M07、ODR-03，再考虑 P2 性能/体验；每项修复附源代码和可复现验收。
4. **许可**：Piko 当前 AGPL-3.0-or-later；仅学习公开功能与技术思路，不直接挪用源码。
5. **范围**：这份报告中的 75 项开源项目调研与 15 组 UI 参考是灵感与候选清单，并非 90 个需要机械移植的新软件模块。
