# 全审计整改：迁移提交安全与操作说明

## 迁移

- 秒传、流式上传和本机中转上传在写入前持久化 `pending`，明确回执后记为 `confirmed`。未知回执记录为 `unknown`，不自动从流式上传降级为第二次本机中转，也不在重启后无条件重传。
- 只有明确未命中秒传时才尝试下一策略。初始化失败与不支持流式上传分别处理，不把登录失效当作“不支持”。
- 已提交但尚未完成任务检查点的项目，持有目标 ID 时复核原始来源及目标后继续收尾；缺少目标 ID 则要求核对，不能凭同名文件推断成功。
- 预检显示逐文件中转方式、最大文件和临时盘可用空间。执行前再次检查并保留 64 MiB 安全余量；大小未知或空间不可读时停止。临时文件结束时清理，Sync 失败不继续上传。
- 同时写入临时盘的其他进程仍可能耗尽空间，预检不等于配额预留。永久不明且无目标 ID 的回执不能自动修复，需要用户核对。

## 登录与交互

- 新增驱动声明的登录方式、字段、必填项、接收方与同意文案。阿里云盘区分第三方令牌中转和自有 OAuth 应用，明确后续刷新也使用中转；自有应用缺少 Client ID 时不回退中转。切换方式移除隐藏凭据。
- 不伪造 Mnemo 已获批的阿里扫码入口。自有应用与真实 OAuth 许可仍为外部前置条件。原有凭据刷新保持兼容。
- 同步预览显示上传、下载、冲突、本地删除和网盘删除数量，显示两侧目录及冲突修改时间；删除计划必须二次确认，旧预览确认不能执行新计划。原有后端重新预检和删除比例保护不变。
- 分享创建前说明访问范围、密码/期限限制和可撤销性，不把链接分享等同于指定用户授权。
- 增加 Ctrl/Cmd+K 命令入口及 Ctrl/Cmd+Shift+F 全盘搜索，保留 Ctrl/Cmd+P 和当前目录搜索。修正登录字段标签及同步删除开关键盘可聚焦性。

## 自动验证

Go 全量测试、go vet、后端编译通过；相关迁移、本机磁盘与应用包竞态测试通过。新增未知流式回执只写一次且不降级、重试不重复、临时空间不足、登录来源拒绝、删除旧预览确认和快捷键测试。前端生产构建通过，仍有既有大分块提示。
