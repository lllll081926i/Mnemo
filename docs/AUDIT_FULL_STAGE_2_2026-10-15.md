# 全审计整改：OneDrive 删除记录与只读回收站

## 实施结果

- 账号级能力覆盖区分个人版恢复、企业只读试验和永久删除。默认不宣称完整云端回收站。
- 本机删除记录持久化账号、空间、原 `driveItem` ID、文件信息和操作状态，不保存凭据。删除和恢复前保存检查点；失败不继续远端写入。同项目操作互斥。
- 恢复校验返回 ID。远端成功但本机回执保存失败时保留待确认状态；再次操作先查询原 ID，不重复提交恢复。企业回收站 ID 不进入个人恢复接口。
- 个人版官网回退使用微软回收站入口。企业版使用 Graph 文档库、根节点和站点元数据交叉确认站点；拒绝其他文档库、外域与伪造分页。
- 用户可主动读取 Graph beta 一级回收站。分页全部成功才返回完整快照；401 单次刷新；403、429、重复条目或不完整响应返回错误，不清空本机记录或上次快照。
- 前端新增本机删除记录弹窗，清除只作用于当前账号和空间。移除账号同时清除该账号全部删除记录。

## 验证与边界

通过 Go 删除检查点故障、丢失恢复回执、跨账号/空间重启与清除、个人恢复 ID 校验、企业只读分页失败和恶意地址回归；相关包竞态测试通过。前端全量 249 项测试与生产构建通过。

ODR-07 的 SharePoint 独立用户授权、ODR-10 的真实个人/企业账号诊断仍依赖外部前置条件。本阶段没有申请更高租户权限，也没有新增 SharePoint REST 写入，不能称为完整企业回收站管理。Graph beta 是实验入口；不通过 mock 推断实际租户已授权。二级回收站、企业恢复与永久删除保持官网处理。
