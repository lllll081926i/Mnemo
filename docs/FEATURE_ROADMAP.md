# 实用新功能建议

状态：第 1、2 项已实现并通过定向验证；第 3～6 项仍为候选，尚未实现。核查基准为 v0.4.3 发布后的代码，日期为 2026-09-27。

## 本轮实现范围

- 整文件夹下载沿用现有单文件下载器：父任务保存扫描清单和检查点，子任务按确定性 ID 入队，保留目录层级与空目录；任务组可暂停、继续、取消和清除，传输页展示扫描状态、文件计数和下载进度。
- 同盘文件复制／移动复用驱动能力；跨账号复制／移动复用迁移任务。文件剪贴板只保存在本次应用进程内，提供右键、选择菜单和快捷键；跨盘移动由迁移引擎确认目标后清理来源。
- 粘贴确认会提示盘内同名项依赖网盘原生处理（部分网盘可能覆盖）或跨盘自动重命名；不承诺盘内各网盘拥有相同的冲突策略。
- 目录下载默认重命名以保留同名项，右键和选择菜单可选择“跳过本地同名文件夹”（只针对选中的根文件夹）；扫描期间文件总数和字节数尚不完整，界面仅显示已发现数量，不表示总体百分比。
- 目录扫描每组最多 100000 项，超过后报错并保留可重试状态。云端源文件在扫描或下载期间变化时，以网盘实际返回结果为准，不保证快照一致性。

## 现状与优先级

项目已有多账号、双栏、跨盘迁移、批量重命名、收藏、跨盘搜索、同步差异预览、预览缓存和传输进度。下一阶段优先补齐日常文件操作，再扩展整理与校验能力。

| 顺序 | 功能 | 主要收益 | 改动规模 |
| --- | --- | --- | --- |
| 1 | 整文件夹下载 | 一次下载完整目录，保留层级与空文件夹 | 较大，涉及任务持久化、路径分配与目录遍历 |
| 2 | 应用内文件复制、剪切、粘贴 | 单栏也能在目录或账号间搬运文件 | 中等，可复用盘内操作和跨盘迁移 |
| 3 | 最近使用 | 快速返回打开过的文件与目录 | 中等，增加本地记录与导航入口 |
| 4 | 双栏目录对比 | 找出两个网盘备份中的缺失项与差异项 | 较大，需要可取消的扫描与差异计划 |
| 5 | 下载内容校验 | 区分“传输完成”和“内容已核对” | 中等至较大，取决于源网盘哈希能力 |
| 6 | 预约传输与分时限速 | 大文件在指定时段传输，减少占用日常带宽 | 较大，需要统一调度和持久化 |

## 1. 整文件夹下载

### 当前依据

- `frontend/src/views/PanView.vue` 的 `doDownload` 会过滤 `isDir` 项，目录没有直接下载流程。
- `internal/transfer/manager.go` 的 `AddDownload` 以单个文件入队，最终路径按全局下载目录与文件名分配；尚无目录任务与相对路径分配。
- 已有下载器支持单文件断点续传；同步可以拉取本地目录，但需要建立同步配置。

### 建议体验

选中文件夹后直接使用“下载”，保留完整目录结构。传输页显示一个可展开的任务组，区分目录扫描和文件下载，展示已发现文件数、已知总大小、失败项与完成量。扫描未结束时不展示误导性的总体完成百分比。

### 首期边界与验收

- 允许文件与文件夹混选，合并重复选中项，避免父目录与子项同时下载两遍；保留空目录。
- 遍历支持取消、分页和有限并发，重复目录或异常分页不会无限扫描。
- 本地名称清理后仍需处理重名、大小写差异、保留名称与路径长度；所有目标路径必须留在用户选定下载目录内，拒绝通过路径片段或符号链接逃逸。
- 同名默认保留两份，支持明确选择跳过；任何目录读取失败都显示未完成状态。
- 保存扫描检查点与文件任务对应关系，重启后继续处理而不重复入队；任务组取消同时停止扫描和未完成子任务。
- 按驱动目录读取与下载能力开放，不依赖服务商提供打包下载接口。

## 2. 应用内文件复制、剪切、粘贴

### 当前依据

`frontend/src/views/WorkspaceView.vue` 已有双栏复制与拖动迁移；`PanView.vue` 已有移动、复制菜单，但文件键盘快捷键中没有复制、剪切、粘贴流程。

### 建议体验

复制或剪切后，用户可以切换目录或网盘，再执行粘贴。待剪切文件使用浅色状态，并显示简短的待粘贴数量。菜单与快捷键指向同一操作：Windows/Linux 使用常见的 Ctrl 快捷键；macOS 遵循文件复制及移动的系统习惯。

### 首期边界与验收

- 首期采用应用内文件剪贴板，记录来源账号、空间、父目录与文件身份；与文本输入框和系统文本剪贴板互不干扰。
- 同一空间复用驱动复制、移动能力；跨账号复制复用迁移队列，粘贴前明确显示来源、目标与冲突策略。
- 剪切阶段只记录意图；执行前校验来源、目标和目录关系，禁止移动到自身或子目录。
- 跨盘剪切仅在目标确认成功并满足现有迁移校验条件后清理来源；部分失败的条目保留为可重试状态。
- 应用关闭或来源账号移除时清空待粘贴内容；重复点击不能重复提交同一批任务。

## 3. 最近使用

现有 `frontend/src/navigation.js` 提供目录前进、后退，`QuickOpen.vue` 提供账号与命令跳转；尚无统一的跨账号最近文件列表。

建议在快捷命令面板加入“最近使用”，另在网盘导航区提供简洁入口。打开过的文件可直接预览或定位，目录可直接进入。只记录用户主动且成功的打开行为，不将预热、缩略图加载或后台扫描当成访问。

记录保存在本机，建议默认保留 30 天、最多 200 条，提供关闭记录及清空入口。不保存临时下载地址、签名链接或凭据；同名文件按账号、空间与文件 ID 区分。文件已移动、删除或账号失效时提示原因，并在已知父目录有效时提供定位入口。

## 4. 双栏目录对比

当前同步差异预览针对本地与网盘，双栏工作区没有两个云端目录的比较视图。建议在双栏加入“对比目录”，先展示仅左侧存在、仅右侧存在、疑似不同、已核对一致和无法确认的条目，再选择需要补齐的文件。

首期只比较和复制，不默认传播删除。大小与时间相同只能作为初筛；确认内容一致需要相同算法和语义的哈希。扫描失败、无权限或未读完的目录不能按“缺失”处理；执行复制前需核对文件是否已变化。深层目录扫描由用户主动开启，避免打开双栏就触发全盘请求。

## 5. 下载内容校验

`internal/app/workspace.go` 的 `VerifyMigration` 已能按条件检查迁移目标大小与共同哈希；下载队列尚无对应的用户入口。

建议为完成的下载增加“校验”操作，并提供可选的下载后自动校验。结果明确区分哈希一致、仅大小一致、无法验证、来源已变化和校验失败。只使用可比较的服务商哈希，不把通用 ETag 当作 MD5；源端没有可信哈希时说明能力限制。哈希计算后台限并发、可取消，默认不为获取远端哈希重新下载整个源文件。

## 6. 预约传输与分时限速

当前有同步定时运行、上传下载限速及优先下载，尚无统一的上传下载预约窗口。建议在传输页提供“稍后开始”，在设置中提供分时限速；首期约定仅在应用运行时执行，重启时明确处理错过的预约。

实施前应统一队列对排队、运行、暂停、重试的调度规则。支持断点续传的任务可以在时段结束时暂停；不支持续传的任务优先在开始前控制调度，避免按时段反复重传。首期不加入自动关机，以免影响其他应用的未保存工作。

## 建议实施顺序

先完成整文件夹下载，形成可恢复的分组任务，再加入文件剪贴板；最近使用可作为独立的小功能跟进。双栏对比、校验与预约传输放到后续阶段，每次单独确定验收范围。

重复文件整理与网盘版本历史暂列候选：前者需要明确的哈希证据与保留规则，后者需逐盘验证接口及账号权限。已有批量重命名和分享识别也可以继续完善，但不宜作为全新的功能重复宣传。
