# 迅雷网盘（thunder）

## 当前支持范围

已注册到通用网盘列表，具有独立图标和账号命名空间 `thunder_`。

| 功能 | 首版状态 |
|---|---|
| 手机号＋密码 / 短信验证码登录、访问 Token 自动刷新 | 已实现；真实账号待验收 |
| 分页浏览、文件详情、文件/目录下载 | 已实现，下载复用统一引擎 |
| 网页视频预览 | 已实现，复用播放会话代理 |
| 建目录、重命名、移动、复制、移入回收站 | 已实现；有任务响应时等待服务端确认 |
| 磁力/HTTP/ed2k 云离线提交、查询、删除 | 已实现，复用统一离线契约 |
| 上传、分享、搜索、保险箱、客户端切换 | 未开放 |
| 回收站列表/还原、永久删除、容量统计 | 未开放 |

## 登录要求

1. 在“添加网盘 → 迅雷网盘”顶部切换“密码登录 / 短信验证码登录”，两个按钮等宽占满右侧表单内容区。密码方式填写手机号和迅雷密码；短信方式填写手机号，获取验证码后填写 6 位短信验证码。设备 ID 与协议签名自动处理，不需要抓 Token 或填写验证码签名。
2. 若迅雷要求滑块或短信安全验证，应用打开官方验证页面。完成后自动续办；页面不支持回调时点击“已完成验证，继续登录”。应用会重新向服务端确认，不绕过验证。
3. 登录后只保存加密的授权会话，不保存账号密码、短信验证码或临时短信校验授权。短信至少间隔 60 秒重发，取消或切换方式不能绕过限制。旧 Refresh Token 账号继续可用；登录失败不会自动循环重试。

短信方式按迅雷官方网页 SDK 的发送 → 校验 → 登录接口实现，沿用驱动移动端客户端身份；未注册的手机号不会被自动注册。当前仅完成模拟协议验收，真实短信及移动端客户端兼容性仍需实测。429 或套餐/文件权限不足不会被误判为账号永久失效；当前请求仍可能受到迅雷服务端风控限制。

Windows 官方安全验证页由应用调用迅雷 SDK 初始化；这是密码登录可能触发的二次校验，与主表单的免密码短信登录入口分开处理。页面组件或必要参数加载失败时显示错误提示，不再留下空白窗口。二次校验返回的临时信任参数与滑块 Token 分开传递，仅用于当前登录尝试。

## 实现与参考

- `internal/drive/providers/thunder/`：独立实现移动端协议，不引入 OpenList 源码或依赖。
- API：`https://api-pan.xunlei.com/drive/v1`；登录刷新：`https://xluser-ssl.xunlei.com/v1/auth/token`。
- 下载仅发送单独的 Android 下载 UA，不转发业务接口的访问 Token 或验证码 Token；不能保证账号套餐允许的下载速度。
- `internal/drive/offline.go` 定义通用离线模型和契约；PikPak 保留原来的 JSON 解码逻辑，仅在驱动边界转换模型。
- 参考：OpenListTeam/OpenList 的 `drivers/thunder/meta.go`、`driver.go`、`util.go`、`types.go`，2026-10-04 读取 main 分支。字段及端点并非迅雷公开开放 API 承诺，可能随服务端调整而失效。
- 设计与验收要求见 `docs/specs/THUNDER.md`。

## 验证边界

包内模拟测试覆盖注册能力、登录配置校验、分页、数字/字符串文件大小、下载 UA 隔离、播放代理、有界 Token/验证码刷新、并发凭据轮换、限流/权限错误、账号隔离、文件操作和离线任务；应用层覆盖创建 → 刷新 → 删除完整链路。现阶段没有使用真实迅雷账号登录或下载，不能把模拟测试等同于真实账号验收。

2026-10-04 验证页修复另以官方实时页面脚本核验短信表单初始化（未发送短信），并以隐藏的真实 WebView2 窗口核验回调。真实账号短信验证与登录仍待用户验收。
