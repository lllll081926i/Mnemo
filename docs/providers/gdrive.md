# Google Drive

更新时间：2026-10-30。驱动 ID：`gdrive`。

## 登录

默认使用 OpenList 在线授权和刷新接口。打开添加网盘窗口，选择 Google Drive，再打开“OpenList 公共授权页面”。在网页选择 Google Drive 和服务端预设应用，完成 Google 授权。将网页的 `refresh_token` 填入客户端。勾选令牌接收方说明后登录。

授权回调返回 OpenList 网页，当前没有自动回传 Mnemo 的协议。不填写 Google 密码，不粘贴完整回调链接。刷新令牌和授权服务地址随账号加密保存。

2026-10-30 匿名实测：公共节点 `api.oplist.org` 与 `api.oplist.org.cn` 返回“OAuth 客户端已删除”，Google 授权入口也出现 `deleted_client`。客户端会显示公共授权服务不可用，不将该错误当作用户令牌失效，也不会自动尝试其他接收方。实际服务可能在后续修复，历史脱敏证据见 [研究报告](../specs/GOOGLE_DRIVE_OPENLIST.md)。

使用可信自建服务时，选择“自建 OpenList 服务”，填写完整 HTTPS 刷新地址，例如 `https://你的服务/googleui/renewapi`。先在该服务自己的网页使用预设应用授权，再导入对应刷新令牌。该服务必须配置有效的 Google OAuth 应用；公共应用签发的令牌不能随意换到不同应用刷新。

根目录留空时使用我的云端硬盘。也可填写文件夹或共享盘 ID；登录时会验证目标确实是文件夹。一个 Google 账号当前保存一个挂载根目录，重新添加同账号会更新账号配置。根目录是浏览起点，不是 Google 权限隔离边界。

## 已实现范围

| 功能 | 行为 |
| --- | --- |
| 账号 | 稳定账号标识、名称、头像、配额；缺少总容量时保留未知状态 |
| 浏览与搜索 | 游标分页、目录排序；搜索当前账号可访问空间，共享盘挂载时限定所属共享盘 |
| 下载与预览源 | 普通文件、Range、Bearer 请求头、本地鉴权代理；每次创建下载源先刷新，长任务按十分钟策略预刷新 |
| 上传 | 预生成文件 ID、分片续传、部分接收偏移、断线查询、MD5 与大小核对、零字节上传 |
| 同名冲突 | 拒绝、跳过、自动改名、覆盖；多个同名目标不做随机覆盖 |
| 文件操作 | 新建目录、重命名、移动；移动读取实际源父目录 |
| 回收站 | 原生列表、移入、恢复、指定文件永久删除；不开放一键清空 |
| 收藏 | 原生收藏列表与增删，完整处理分页 |
| 快捷方式 | 保留快捷方式自身 ID；目录浏览和下载解析目标，状态修改作用于快捷方式 |
| 网页打开 | 校验 Google Drive / Google Docs 网页地址 |

上传会话与预生成文件 ID 写入现有检查点存储。恢复使用原目标 ID，避免重复创建文件。服务端返回 308 时只按 `Range` 确认已接收字节。最终必须重新读取目标详情并核对 ID、目录、名称、大小与 MD5。远端已确认完成后，凭据保存失败单独通知，不使文件进入重传。

401 最多刷新并重放一次；网络异常不盲重试写请求。错误通过应用现有统一通知处理。刷新 URL 查询、令牌和上游原始正文不会拼入用户错误。

## 限制与验收边界

- Google 原生 Docs、Sheets、Slides 当前提供网页打开；未实现导出下载。不把缺失大小当作零字节成功。
- 同盘复制、分享、离线下载、哈希秒传暂不开放；Google 返回 MD5 不表示存在哈希秒传协议。
- 共享盘需账号拥有相应权限；列表不完整、分页游标循环会报错，不返回部分结果假装成功。
- 文件列表与传输仍需能够访问 Google 官方 API。OpenList 在线接口只中转令牌。
- 已有模拟协议测试不代表真实账号验收。真实浏览器授权、有效令牌刷新和真实网盘读写仍待有效 OAuth 服务与账号验证。

详细协议、固定上游提交与接入依据见 [接入研究](../specs/GOOGLE_DRIVE_OPENLIST.md)。
