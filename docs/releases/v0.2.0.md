# Mnemo v0.2.0

**沉浸式播放体验 + 托盘常驻 + 单实例**，以及一批交互与稳定性打磨。共 28 个提交。

## 播放器重做

- **Netflix 风沉浸式控制层**：渐变遮罩顶/底栏、悬浮大播放钮、细线进度条（悬停加粗出拇指）、静止 2.6s 自动隐藏控件、全屏切换缩放过渡动画
- **音量 0–200%**：超过 100% 走 WebAudio Gain 增益；右半屏滚轮调音量、左半屏滚轮调亮度（20–200%），带 OSD 提示药丸
- **字幕体系**：SRT/VTT 文本轨；自研 PGS/SUP 图形字幕解析与 canvas 渲染（锁定 16:9 区域）；ASS 特效字幕由 jassub（libass WASM）按需懒加载渲染；网盘同名字幕自动挂载 + 本地字幕文件选择
- 玻璃拟态二级菜单（倍速/字幕/播放列表/清晰度）、清晰度按钮常显、截图 toast、对称快退/快进图标
- 网页播放器全面替代 mpv（HTML5 + HLS.js/dash.js），修复 webview2 init panic

## 托盘常驻与单实例

- **系统托盘图标**：左键点击恢复主窗口，右键菜单「显示 / 退出」
- **关闭不退出（默认开启）**：点 X / Alt+F4 / 任务栏关闭都收进托盘，进程保留、下载不断；设置 → 基础 可关闭此行为
- **退出前下载确认**：真正退出时若有进行中下载任务，唤回窗口并弹原生确认框，任务下次启动可续传
- **单实例**：二次启动 / 双击快捷方式 / 点托盘图标都唤起已有窗口（命名事件通知 + 置前），不会新开进程

## 界面与交互

- 设置页重排为 macOS 卡片式分组（基础/文件/传输/播放/连接/缓存/日志/更新），全部即时静默保存
- 顶部页签改轨道式分段控件（柔雾紫滑块）、分割线图高光收敛为细线微光
- **账号栏手动拖拽排序**：幽灵克隆跟随指针、邻项平滑让位动画，顺序持久化，重启保持
- 打开应用恢复上次使用的网盘；经典无边框窗口控制按钮；屏蔽原生右键菜单
- 通知样式重做、传输操作即时同步；WebDAV 预置服务商；PikPak 登录加固与开发模式兜底

## 修复

- 分享页多根节点导致 Transition/KeepAlive 卡死、切页后内容消失
- 托盘消息循环未锁定 OS 线程导致托盘静默失效（表现为关闭按钮无反应）
- UiSelect 隐形空白、右键菜单冗余项、PikPak 验证登录自动续办、传输运行时开销
