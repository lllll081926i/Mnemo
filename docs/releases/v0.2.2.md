# Mnemo v0.2.2

这是一次以网盘分享、界面动效和账号个性化为主的版本更新。

## 网盘分享与传输

- 新增网盘分享能力，支持创建与管理分享链接。
- 改善网盘下载稳定性，修复分享与下载链路的问题。
- 完善网盘容量展示与上传大小限制，修复阿里账号显示与光鸭云容量。

## 连接与登录

- 修复 139 云盘与天翼云盘的登录会话保持。
- 修复部分网盘登录与代理链路问题。
- 登录页全面精调：隐藏可选高级字段、精简说明文字、统一边距与微动效；切换动画改为纵向滑入。
- WebDAV 预设 InfiniCLOUD 默认服务地址更新为 `https://miya.teracloud.jp/dav/`。

## 界面与体验

- 视频播放器新增经典控制三件套与缓冲实时网速显示。
- 图片预览沉浸式重写，浮动控件在亮色图片上不再消失。
- 预览与播放器增加窗口控制按钮，预览页新增沉浸式渐变标题栏。
- 全局动效灵动化：弹簧曲线加强、拖拽让位波纹与果冻回弹、账号栏弹簧跟随。
- 目录树展开/收起高度动画，文件区按目录切换过渡；修复悬停预览与展开动画冲突。
- 网盘页位置持久化：切走再切回或重启后恢复到上次浏览的目录。
- 设置页控件现代化重做。
- 移除桌面传输悬浮球功能，简化桌面交互。

## 账号个性化

- 侧边栏账号支持自定义昵称与自定义图标（支持本地位图/SVG 上传与交互式裁剪）。
- 侧边栏账号支持自定义截图背景与正下方半透明毛玻璃药丸通知。
- 侧边栏及全局 WebDAV 各预设服务商图标智能识别。

## 稳定性与数据安全

- 防止凭据密钥损坏时静默重置，避免本地加密数据意外不可用。
- 加固错误分类与下载状态写入。

## 已知限制

- 分享能力以各网盘开放接口为准，不支持分享的 Provider 不展示相关入口。
- 大型前端组件拆分和完整页面级 E2E 暂不纳入本次小版本。
