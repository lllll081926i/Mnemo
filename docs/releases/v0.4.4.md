# Mnemo v0.4.4

本次更新新增迅雷网盘，补齐云离线入口，并集中修复下载续传、上传完成确认、迁移删源保护和登录体验。

## 迅雷网盘

- 新增手机号密码与短信验证码两种登录方式，可在登录页直接切换。设备参数和协议签名由应用处理，不再要求填写 Token 或验证码签名。
- 需要人机验证时打开官方验证窗口，居中显示；支持验证回调和手动继续，组件加载失败时显示错误，不再留下空白窗口。
- 支持文件浏览、文件与目录下载、视频预览、容量刷新、建目录、重命名、移动、复制和移入回收站。
- 支持回收站列表、还原和选中条目永久删除；支持组合分享、永久或 1–7 天有效期、分享历史和远端撤销。提取码由服务端生成。
- 支持磁力、HTTP、ed2k 云离线任务的提交、查询和删除。迅雷尚不支持本地上传、分享转存、保险箱及一键清空回收站，不能作为普通跨盘迁移的目标。

## 下载与云离线

- 修复 PikPak 已实现云离线却被能力开关拦截的问题；接入光鸭云离线。只有完整实现对应接口的网盘才显示入口，账号权限和任务额度仍由服务端决定。
- 统一检查各网盘的下载请求头、连接策略、全局限速和重试边界。迅雷使用独立移动端下载 UA；部分服务错误耗尽普通重试后可有界降为单连接继续，不掩盖权限或限流错误。
- 修复光鸭 CDN 修改时间不一致导致下载立即失败的问题。不能安全分段时改用完整单流，继续核对实际资源身份，不将不同版本的字节拼接。
- 分片保留已写入的有效前缀，减少迅雷恢复时进度回退和重复下载；单流及分段下载增加周期检查点，重启后从有效检查点恢复进度，不再仅依赖任务列表的旧进度。
- 小文件与单流降级路径也支持可验证的断点续传。服务端不支持 Range、资源发生变化或无法确认资源身份时，仍需重下或明确报错；旧版未保存的断点无法追溯恢复。
- 下载失败日志补齐具体错误、阶段、字节数、配置连接数及耗时，任务详情保留脱敏错误。没有进行中的下载时清除任务栏进度，恢复系统默认指示。

## 上传、分享与迁移

- 修复 PikPak 上传指纹重复编码、阿里上传续传进度重复累计、光鸭分片取消后仍占用文件，以及多种哈希路径不响应取消的问题。
- OneDrive、天翼等上传必须取得有效完成回执才显示成功；上传源短读不能作为成功分片提交。补齐 Dropbox 小文件令牌续期、可重放正文和会话提交处理。
- 重启后的未完成上传恢复为可手动继续的暂停任务；退出时等待上传与迁移保存状态。上传失败事件提供具体原因，进度与速度不再由迟到回调覆盖任务状态。
- 修复 123 分享列表分页、阿里分享转存空间路由与链接提取码、Dropbox 旧链接复用条件，以及 PikPak 非法有效期的处理。分享转存提示“已提交”，不把请求接收当成文件已经落盘。
- 移动迁移在删除来源前重新确认目标文件及可比较的哈希；目标缺失、大小异常、缺少可靠文件 ID 或检查点保存失败时保留来源，避免未经确认删源。

## 文件操作与界面

- 支持整文件夹下载；支持应用内复制、剪切、粘贴，跨网盘操作接入迁移流程；新增最近使用入口及相关设置。
- 优化登录页布局，登录方式切换与表单统一宽度。左侧网盘列表隐藏滚动条并保留滚动；验证码按钮统一样式。
- 检查二级页面关闭按钮的位置，统一贴近右上角；优化主题弹窗，修复点击退出确认后应用没有真正退出的问题。
- 替换下载完成提示音，提供两种音效切换与试听，保留总开关；调整网盘图标显示。
- 更新开发依赖的安全补丁，修复依赖审计发现的拒绝服务漏洞。

## 升级与安装

- 应用更新器、下载链接和包信息统一指向正式仓库：<https://github.com/lllll081926i/Mnemo>。
- **若旧版检查更新无法识别安装包，请从本版本发布页手动下载对应架构安装包并覆盖安装。不要卸载或删除用户数据目录。** 旧版的仓库路径校验无法通过新版本说明修正，升级后使用新的更新器。
- Windows 提供 x64、arm64 安装器；Linux 提供 x64、arm64 的 DEB、RPM、Arch、AppImage 和归档；macOS 提供 Apple Silicon 的 DMG 和归档。发布附件附带 SHA-256 校验清单。
- 本版本不新增 macOS Intel 构建，不宣称安装包已完成商业签名或 Apple 公证。

## 验证与限制

本机全量 Go 测试、竞态检查、静态检查、编译、前端测试及生产构建通过；浏览器验收覆盖登录方式切换、工作区与二级弹窗。正式包由 GitHub Actions 构建，不生成本地验证安装包。

以上自动化核验不等于所有真实网盘账号、套餐和第三方协议都已联机验收。迅雷新增接口及真实短信、风控仍需按账号确认；不承诺突破服务商限速。部分上传仅能重新提交，跨盘迁移仍按文件保存检查点，不具备所有网盘正文级续传或下载上传并行。移动迁移保护不构成跨云事务，重要文件请先小范围验证并保留备份。
