# Mnemo v0.4.8

本次更新集中完成三件事：失效账号可直接重新登录、传输与同步的状态反馈更可靠、预览与文件列表的操作更顺。同时恢复 Google Drive 支持。

## 账号与重新登录

- 账号失效后可在侧栏右键菜单直接选择「重新登录」，无需先删除账号。原账号、收藏、任务与断点全部保留。
- 重新登录只更新凭据。授权返回的账号或网盘空间与原账号不一致时拒绝写入，原账号保持不变。
- WebDAV 与 S3 挂载复用原连接目标，只替换新的密码、密钥或临时会话令牌，不会新建账号。
- 失效标签不再闪烁或消失，侧栏展开与收起时的底色错位已修复。

## 传输中心

- 下载、上传、云离线与迁移任务拆分为独立行组件，状态、进度与详情分行显示，长列表滚动更稳。
- 「新建下载」支持填写 User-Agent、Referer 与 Cookie。批量提交时逐条反馈，失败链接保留在原对话框中可直接重试，不必重新粘贴。
- 任务行不再堆放原始错误码。失败原因进入通知入口，重试只提交失败项。

## 同步

- 同步预览按上传、下载、删除本地、删除网盘与冲突分类筛选，冲突策略可按条目选择「保留两份」「使用本地」或「使用网盘」。
- 运行中的任务显示完成数与总量的实际进度，不再只显示「运行中」。
- 每次同步的启动与结束状态都会落盘，重启后不再显示上一次的旧结果。
- 退出应用时先关闭同步入口，再取消执行并等待结束状态保存完成，避免退出过程中启动新任务。

## 网盘文件界面

- 新增文件缩略图。加载失败的缩略图自动退回图标，不再反复请求。
- 列表与网格分别记忆滚动位置，切换账号、搜索词与视图时各自恢复。
- 虚拟列表在像素滚动没有跨越行边界时复用已渲染窗口，大目录滚动不再逐行重新排版。
- 拖动目录栏宽度时每帧最多提交一次，松手后保存最终值。

## 预览窗口

- 图片预览新增缩略图胶卷条，可沿当前目录的图片连续切换。
- 音频预览新增播放列表，多音轨可直接跳转。
- 文本与代码预览改为流式读取，超过 4 MB 的文件直接提示下载到本地查看，不再把整个文件载入内存。
- PDF、Word 与演示文稿支持输入页码跳转，保留连续滚动。
- 图片缩放以光标位置为锚点，放大后不会偏离目标区域。

## 交互与可达性

- 弹窗支持多层堆叠：`Esc` 只关闭最上层，下层弹窗在堆叠期间不可交互，关闭后焦点回到打开它的元素。
- 下拉菜单、选择器与搜索结果面板补齐键盘焦点保持与活动项关联，高对比度模式下保留可见焦点。
- 页面切换不再为旧页面额外占用绘制帧，滚动位置与页面缓存继续保留。
- 减少动态效果开启时，关闭非必要的位移与加载脉冲。

## Google Drive

- 恢复 Google Drive 支持，优先使用 OpenList 在线授权与刷新。授权能否完成仍取决于在线授权服务。

## 设置

- 修复选择下载目录时的重复系统对话框与旧回执覆盖新选择的问题。
- 提示音音量改为松手后提交，试听不再被滑块抖动打断。
- 修复限速值在显示与保存之间的小数截断。

## 升级前请留意

- 从 v0.4.7 覆盖安装即可，无需删除本地账号、任务或断点数据。
- 旧版中已失效的账号不会自动恢复，需要手动选择「重新登录」。
- 缩略图由网盘返回的链接提供。部分网盘不提供缩略图，或链接有时效限制，此时仍显示文件类型图标。
- 工具链升级为 Go 1.27.4。云端构建与本机核验使用同一版本。

## 下载与验证

- Windows：x64、arm64 安装程序。
- Linux：x64、arm64，提供 AppImage、deb、rpm、Arch 包与 tar.gz。
- macOS：Apple Silicon，提供 dmg 与 tar.gz。
- 附 `SHA256SUMS.txt`、`Mnemo-compliance.tar.gz` 与 GitHub 构建来源证明。来源证明不等同于 Windows 代码签名或 macOS 公证。

本版通过后端单元测试、竞态检查、前端组件测试、依赖审计与漏洞扫描，并完成桌面开发模式启动核验。协议测试与界面检查使用模拟响应，不能替代所有真实网盘账号、套餐、风控与大文件场景的验收。
