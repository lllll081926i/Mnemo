# Mnemo v0.2.1

这是一次以稳定性、安全性和发布链路为主的小版本更新。

## 连接与登录

- WebDAV 增加 Basic、Digest、Bearer 和自动协商，改善部分服务返回非标准 `530` 状态时的诊断信息。
- WebDAV 供应商预设扩充，选择预设后会自动填写连接名称、Endpoint 和根路径。
- 修复登录密码输入框重复显示两个眼睛的问题。
- S3 连接校验增加受控的 `HeadBucket`/`ListObjectsV2` 兼容回退；写入权限验证保持默认关闭，避免连接测试产生不必要的副作用。
- 增加默认关闭、按连接主机限定的内网媒体预览授权。

## 稳定性与数据安全

- 同步、下载、上传和迁移补强取消、并发隔离、路径边界和断点状态保护。
- 迁移支持逐资源恢复检查点，避免中断后重复上传已完成文件。
- 云端文本编辑现在会等待上传进入最终状态后再提示保存成功。
- 大目录增加虚拟渲染，保持现有界面样式和交互数据模型。
- 容量刷新增加账号级去重、缓存、冷却和可见性保护，降低 PikPak 等服务触发风控的概率。
- 本地预览代理加强私网访问、重定向和文件授权边界。

## 构建与测试

- Linux 发布产物扩展为 `.deb`、`.rpm`、`.pkg.tar.zst`、`.AppImage` 和 `.tar.gz`。
- 安装后应用名称、快捷方式和 Linux desktop/AppImage 名称统一为 `Mnemo`，不携带版本号。
- Release 工作流增加 Go 测试、vet、编译、前端 Vitest 和前端构建质量门禁。
- 本地验证覆盖 Go 全量测试、目标包竞态测试、前端 13 个测试、Vite 构建、`go build` 和 `go vet`。

## 已知限制

- 本版本仍不对 S3 做全桶扫描来估算容量；没有明确配额 API 的 Provider 继续显示容量未知。
- 大型前端组件拆分和完整页面级 E2E 暂不纳入本次小版本。
