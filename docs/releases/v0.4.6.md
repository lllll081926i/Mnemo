# Mnemo v0.4.6

这次更新以界面精简和操作体验为主：少一些说明，多一些直接操作。

## 更清爽的登录

- 登录页只保留当前方式需要的字段。密码登录、短信登录等宽切换，手机号保持不变，旧密码或验证码随方式切换清除。
- WebDAV、S3 的可选连接项收进“高级设置”，基础连接信息更容易找到。
- 打开登录页即可输入账号；网盘列表支持方向键、Home 和 End，隐藏滚动条但仍可滚动。
- 保留第三方令牌授权确认、短信冷却和官方人机验证。详细授权说明按需展开，不再占满表单。

## 更直接的页面交互

- 普通二级弹窗只显示关闭按钮，不再重复控制主窗口；文档与媒体预览保留原有窗口控制。
- 表单优先聚焦输入，确认操作优先落在底部操作区。保留 Esc、焦点恢复和危险操作确认。
- 文件筛选改用“全部文件”“图片与视频”“文档与影音”，保留列表、网格、预览和播放功能。
- 精简设置、分享、搜索、我的空间和播放信息中的重复说明。诊断工具默认收起，展开后自动读取本机账号。
- 任务错误码和更新来源移入详情。修正更新包下载前就显示“已通过校验”的不准确提示。

## 减少无效开销

- 下载、上传进度通过任务索引定位，避免每次更新扫描整个任务列表。
- 收藏标记使用集合查询，减少目录渲染中的重复查找。
- 普通弹窗不再查询主窗口最大化状态；传输页隐藏后，不再因迟到的轮询响应重建定时器。
- 更新 Vite、Vitest 补丁依赖，修复开发服务与测试工具的已知安全问题。
- 正式安装包使用 Go 1.27.3 构建，包含证书验证安全修复。

## 升级说明

- 从 v0.4.5 覆盖安装即可，无需删除账号、任务或断点数据。
- 提供 Windows x64/arm64、Linux x64/arm64 和 macOS Apple Silicon 构建，附 SHA-256 清单及依赖许可归档。
- 本版不改变网盘协议或套餐限制。自动化回归不等同于所有真实账号、短信和服务端环境均已实测。
