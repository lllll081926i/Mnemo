# Mnemo v0.4.7

这次更新集中修复上传完成状态与回收站问题，同时带来纸感、黑白主题和更紧凑的文件界面。文档可以连续向下阅读，账号图标也有了更多选择。

## 上传与秒传：完成状态更准确

- 修复阿里云盘已秒传成功，客户端仍提示“上传结果未知”的多条协议与回执路径。正确处理文件证明、已有文件校验和实际文件名，秒传未命中时复用已创建的上传会话，减少重复创建。
- 重新核对 PikPak、123 云盘、移动云盘、天翼云盘、蓝奏云优享版和光鸭云盘的秒传完成条件，避免将缺失参数或未完成的回执当作上传成功。
- 新增迅雷本地文件上传：支持 GCID 秒传探测、普通上传和大文件分片上传，并确认服务端完成状态。支持重命名、跳过和拒绝同名文件；暂不提供覆盖同名文件。
- 上传前的本地文件与参数错误不再误标为“待核对”。远端上传已完成后，即使本地凭据保存失败，也会单独通知，不再诱发重复上传。
- 上传、下载和迁移失败统一进入通知中心。任务行精简为状态与通知入口，不再堆放原始错误码和展开日志。

**仍需核对的情况：** 网络中断、完成回执丢失或本地记录保存失败时，客户端可能仍无法证明远端结果。此时继续保留核对与防重复写入流程；请先检查目标目录，再决定是否重试。

## 回收站与 PikPak

- 修复 123 云盘回收站请求中不兼容的筛选参数，解决服务端将 `[]` 解析为整数而导致的“加载回收站失败”。同时修正回收站列表参数、成功状态码和分页处理。
- 修复蓝奏云、蓝奏云优享版回收站的空列表、响应包装与表单令牌解析。
- 阿里云盘 Open 授权不提供当前客户端所需的回收站列表与恢复接口。本版改为官网管理入口，不再请求不兼容的网页接口。其他受影响网盘加载失败时也可通过官网入口处理。
- 修复切换到 PikPak 时自动加载收藏报错，补齐收藏请求与会话刷新处理。

## 主题与文件界面

- 新增纸感、黑白两套外观，均支持浅色、深色与跟随系统，并提供 OLED 纯黑选项。
- 重设计顶部四页面导航：图标搭配文字、滑动指示动画，并通过短竖线区分项目名称与导航。
- 收紧顶栏、面包屑和工具栏。统一左右边距，调整新建、上传、刷新等操作的位置，保留轻描边，减少重复分隔线。
- 顶部加入搜索输入框，输入关键词后可直接进入全盘搜索。
- 文件界面新增目录分栏视图，可沿目录层级连续浏览；保留列表、网格和双栏迁移视图。
- 优化侧边栏的目录自然排序与缩进，修复账号较多时首项被遮挡及滚动高亮跟随问题，并校正部分导航图标。

## 连续阅读与更新窗口

- PDF、Word 和演示文稿改为连续纵向滚动，移除上一页、下一页按钮；表格保持连续滚动浏览与工作表切换。
- 重做“检查更新”居中弹窗：版本、下载进度、发布说明和操作按钮更清楚，并保留取消下载、校验和安装确认流程。
- 账号可选 SVG 图标扩充至 **55 个**，新增 19 个品牌图标与 12 个原创通用存储图标。支持中文、英文和文件名搜索，图标随应用内置，新增品牌图标的许可与来源随安装包归档。

## 升级前请留意

- **一刻相册已完全移除适配**，不再提供登录或文件操作。当前支持 13 个网盘与存储驱动；图标库中的其他品牌仅用于自定义外观，不代表新增网盘支持。
- 从 v0.4.6 覆盖安装即可。无需删除本地账号、任务或断点数据。已有“待核对”上传请先核对远端结果，升级不会自动重新提交这些文件。
- 秒传能否命中仍由网盘服务端、账号权限和文件内容决定。不同网盘的同名处理规则仍有差异，重要文件请在操作前确认目标目录与冲突策略。

## 下载与验证

- Windows：x64、arm64 安装程序。
- Linux：x64、arm64，提供 AppImage、deb、rpm、Arch 包与 tar.gz。
- macOS：Apple Silicon，提供 dmg 与 tar.gz。
- 附 `SHA256SUMS.txt`、`Mnemo-compliance.tar.gz` 和 GitHub 构建来源证明。来源证明不等同于 Windows 代码签名或 macOS 公证。

本版执行前后端自动化回归、竞态检查、构建与依赖安全检查。协议测试与浏览器检查包含模拟响应，不能替代所有真实网盘账号、套餐、风控和大文件场景的验收。
