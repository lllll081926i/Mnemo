# Mnemo v0.4.3

本次更新重点是让网盘操作更清楚、预览更顺手，并补齐天翼云盘回收站的应用内入口。

## 主要变化

- **网盘文件操作**：按“未选择文件 / 已选择文件 / 回收站”分别显示工具栏，减少重复按钮；选择改为下拉菜单，支持全选、反选、区间选择与取消选择。切换目录时清除旧选择，后台刷新时保留仍存在的文件选择。
- **传输过程可见**：上传和跨盘迁移显示哈希计算、秒传或续传检查、来源下载、目标上传和服务端确认等实际阶段；不支持相应能力的网盘跳过无用阶段。修正轮询覆盖实时进度、批量操作数量与部分失败反馈。
- **预览与播放**：图片请求按账号隔离，音视频拖动进度条时不再被旧播放时间拉回；Office 小文件复用本地预览缓存，DOCX 优先尝试完整排版并在失败时回退兼容模式。PDF、DOCX 出错后可在当前页面重试；二级预览标题栏改为更紧凑的单行布局。
- **OneDrive 文档编辑入口**：受支持的 Office 文档可从预览跳转 OneDrive 官网编辑；PDF 可跳转官网打开。编辑在浏览器中完成，需要登录同一账号，应用内预览仍为只读。
- **回收站**：天翼云盘可在应用内查看个人云与家庭云回收站，并提供恢复操作；OneDrive 保留官网入口，不把不完整的 Graph 查询结果伪装成完整回收站。
- **其他交互**：目录缓存刷新失败时保留已有文件并显示重试提示；上传文件选择和冲突检查固定原账号、原目录，避免切换页面后误传；下拉菜单再次点击按钮可直接关闭。
- **搜索、分享与同步**：全盘搜索同时查询在线结果与本地缓存，修正 OneDrive 搜索结果的父目录定位；分享历史刷新失败时保留已有记录，手填提取码不会被旧请求覆盖；同步和目录选择加载失败后可直接重试。
- **账号与设置**：手动刷新容量时发起真正的强制请求，避免账号资料刷新重复预热根目录；设置页不再等待日志路径才显示主要内容，更新提示更清楚地说明已知版本与缺失的安装包。

## 使用说明与限制

- 天翼云盘回收站的个人云、家庭云列表已用真实账号只读验证；恢复操作目前仅通过模拟接口测试，请先用非重要文件小范围确认。
- OneDrive 个人版目前无法通过现有 Graph 授权可靠列出完整回收站，应用内不提供虚假的列表或清空操作；浏览器编辑能力由 OneDrive 官网和文件权限决定。
- DOCX 复杂版式仍受 `docx-preview` 与系统字体限制，不保证与 Word 像素级一致。PDF 保持按需读取，不会作为 Office 小文件整包缓存。

## 验证

发布前本机执行 Go 测试、前端测试、Go 静态检查与格式检查；安装包由 GitHub Actions 在 Windows、Linux 和 macOS 环境构建，不在本机打包。
