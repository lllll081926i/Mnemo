# Mnemo v0.4.5

这次更新围绕传输安全、账号管理和文件操作体验展开。重点是让中断、超时和权限不足时的处理更可靠，避免重复上传、误覆盖或误删来源文件。

## 更可靠的上传与跨盘迁移

- 上传前完整检查选择的文件。扫描失败会明确提示，不再悄悄漏掉部分文件。
- 普通上传保存提交回执。网络中断、超时或重启后，如果无法确认云端是否已经完成，任务会保留“待核对”，不自动重复提交。
- 同一账号、目录和文件名的写入串行处理。S3、WebDAV 覆盖使用条件写入，发生冲突时不回退为无条件覆盖；PikPak 不再通过预先删除旧文件来实现覆盖。
- 大文件上传使用独立网络期限，避免套用普通控制请求的总超时。检查点保存失败时停止后续提交，不再显示成已经可靠保存。
- 迁移前检查嵌套目录重名和本机临时空间。目标提交结果不明时保留来源；部分完成会显示实际失败原因，不把整个任务当成成功。
- 下载可按设置使用 MD5、SHA-1 或 SHA-256 校验；校验失败不覆盖已有目标文件。

## 账号、登录与网盘能力

- 凭据失效后保留账号、缓存和任务关联，提示重新授权；重新授权成功后清除失效状态。
- 登录字段的用途、默认值、输入方式和显示条件由驱动声明。切换授权来源会清除不再使用的凭据及同意记录，保留各平台现有短信和人机验证流程。
- 阿里云盘明确区分第三方令牌中转与自有 OAuth 应用，并展示令牌接收方和续期说明。没有获批应用时不提供虚假的官方扫码入口。
- 文件页新增可展开的“账号能力与使用条件”。S3/WebDAV 区分浏览与写入条件；移动云盘、天翼云盘说明个人云与家庭云限制；蓝奏云说明配置的单文件上限不等于实际会员权限。
- OneDrive 区分本机删除记录、个人版恢复与企业版一级回收站只读预览。企业恢复和永久删除仍不开放，相关操作可转至官网。
- macOS Keychain、Linux Secret Service 增加密钥保存适配；Windows 继续使用 DPAPI。系统条目解锁失败或丢失时，不会自动换钥导致原凭据无法解密。旧兼容密钥仍保留读取路径，不自动删除。

## 文件工作区与任务提示

- 新增“我的空间”本机概览，集中查看账号状态、缓存容量、待处理任务、最近失败和最近使用入口。
- 双栏可固定目标位置。复制、移动前展示源、目标和选择项，切换账号会取消待确认计划。
- 新增相册、阅读与播放工作模式，筛选当前已加载内容，不自动扫描整个网盘。
- 跨盘搜索分账号显示结果与失败，说明缓存覆盖和完整性；在线搜索不再因本机固定条数而提前截断。
- 下载、上传、目录、迁移、同步和云离线统一展示失败原因、核对建议及冷却时间。诊断中心可按需检查本机环境和指定账号的只读访问，并导出脱敏结果。
- 分享转存保存本机回执，重启后避免重复提交；分享历史补充期限、到期提醒和访问范围说明，不将本机记录冒充完整云端历史。
- 修复侧栏网盘排序保存时序，统一多处操作文案，改善快捷键、下拉控件及弹窗焦点处理。

## 预览与依赖分发

- 图片、音频、文本、文档和视频预览在关闭、切换及迟到回执到达时释放会话，减少旧预览继续占用资源。
- 修复媒体代理续签并发、取消和响应上限处理；播放信息只展示实际读取到的流类型、画面尺寸等信息，不猜测 HDR 或硬件解码状态。
- 为补齐依赖分发材料，ASS/SSA 字幕固定使用自带完整许可及组件署名的兼容渲染版本，保留特效、内置字体、SIMD 和时间偏移；移除三项许可正文证据不完整的间接依赖。
- 安装包附带第三方许可、依赖清单和 SBOM；发布附带合规归档与 SHA-256 清单，并由云端生成 GitHub Artifact Attestation。应用内更新仍只校验来源地址、大小和摘要，不等同于验证原生代码签名。

## 升级与使用边界

- 从 v0.4.4 覆盖安装即可。升级前建议备份用户数据目录；不要先卸载或删除账号、任务和检查点数据。
- 老任务遇到无法可靠确认的云端提交结果时，需要先核对目标目录，再决定是否重试。不是所有网盘都支持上传正文断点续传或未知提交自动对账。
- 网盘套餐、目录权限、短信风控和服务端条件写入行为以真实平台响应为准。本版不承诺突破服务商限速，也不将自动化检查等同于全部真实账号验收。
- macOS/Linux 原生凭据授权提示、原生辅助技术和部分媒体兼容性仍需对应桌面环境确认。缺少系统凭据后端时可能保留权限受限的兼容密钥文件。
- 提供 Windows x64/arm64、Linux x64/arm64、macOS Apple Silicon 安装包。未新增 macOS Intel 构建，不宣称已完成 Windows 商业签名或 Apple 公证。
