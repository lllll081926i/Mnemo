# Mnemo v0.4.9

本次更新聚焦性能提升、界面质感统一、实用新能力补齐以及网络与下载安全加固。

## 性能与体积优化

- **移除冗余依赖并瘦身主包**：移除未使用的 `@vueuse/core` 与过重的 `motion-v`（改为轻量原生 CSS 过渡），并将更新、头像裁剪、目录选择、批量重命名等低频弹窗改为按需懒加载。
- **大目录滚动与选择更流畅**：网盘列表与网格视口行状态单次预计算（消除重复查询），滚动记忆防抖写入，`ResizeObserver` 回调合批到 `requestAnimationFrame`；账号栏展开/收起过渡期间跳过冗余布局测量。
- **大文本编辑零卡顿**：文本预览/编辑器改用零分配行数统计与光标位置扫描，行号块缓存复用，编辑模式跳过全量预览分块与 Markdown 解析；图片拖拽平移时暂停浮层高开销 `backdrop-filter`。
- **传输与分享页减负**：下载/上传状态单次遍历分桶，历史已完成列表改为 120 条分段按需加载；清理分享页 `deep: true` 监听并预计算行状态。

## 视觉与侧边栏升级

- **统一全站原生桌面风格**：全面去除文件侧边栏、文件列表、任务行与登录列表左侧生硬的装饰竖条，改为克制的整体选中底面与低饱和层次。
- **文件侧边栏与账号栏优化**：为文件侧边栏增加「快速访问 / 目录」清晰分区与弱化层级参考线；账号栏展开/收起时图标保持稳定左对齐，文字信息分阶段平滑淡入。

## 实用新功能

- **在线 ZIP 压缩包预览**：基于本地 Range 代理零依赖按需读取 ZIP/ZIP64 中央目录，无需下载整包即可秒开浏览目录树、搜索包内文件并按需提取单个文件（支持 50,000 条目虚拟滚动）。
- **网盘侧边栏「最近使用」入口**：在「快速访问」分组直接展开当前账号最近打开的文件与目录，支持快速跳转与单项移除。
- **下载内容完整性校验**：在传输中心「已下载」列表支持一键校验本地文件，采用 1 MB 固定缓冲流式计算 MD5/SHA1/SHA256 与网盘可信哈希比对，明确区分哈希一致、仅大小一致与异常。
- **双栏目录对比**：双栏工作区新增「对比目录」，支持 O(N) 归类仅左栏、仅右栏、差异与一致项，并支持一键单向补齐复制。
- **全盘在线搜索慢源超时保护**：为单账号在线搜索增加 10 秒独立超时预算并自动取消超时请求，避免未配代理的慢源拖死整轮搜索。
- **123 云盘并发分片上传**：多片上传升级为 3 并发 Worker 池并批量落盘断点，同时保留预签名过期去重刷新与断点续传。
- **双向同步重命名追踪**：同目录下一删一增且大小与内容哈希唯一匹配时，自动折叠为本地或远端重命名，省去重复上传下载并避免误触发大批量删除保护。

## 安全与稳定性修复

- **HTTP 重定向安全守卫**：统一拒绝 `HTTPS → HTTP` 降级重定向，跨主机重定向自动剥离敏感认证头（`Authorization`、`Cookie`、Token 头）。
- **蓝奏云下载端点兼容**：兼容蓝奏云返回的完整绝对 URL（`ajaxm.php` / `ajaxfile.php`），避免拼错域名导致下载失败。
- **磁盘空间不足快速失败**：多线程下载遇到磁盘空间不足或本地权限错误时立即终止，不再无效重试。
- **前端细节修复**：修复 3 处未定义 CSS 变量（`--color-danger` / `--border` / `--fs-aux`）、修复 `ImageCropModal` 卸载时拖拽监听泄漏、校准主窗口最大化状态并补齐顶部按钮 `aria-label`、Markdown 外链拦截交由后端 `OpenBrowser` 安全打开、统一收敛 Wails Bridge 调用至 `api.js`。
