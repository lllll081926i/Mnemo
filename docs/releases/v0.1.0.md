# Mnemo-Go 发版记录

## v0.1.0 — Go 重写版首版

**里程碑**：用 Go + Wails v2 完整重写 Mnemo 多网盘桌面文件管理器。

### 架构

- **桌面壳**：Wails v2（Go 后端 + WebView2 前端）
- **前端**：全新精简 Vue 3 + Vite（复用旧版 design-tokens 样式）
- **下载引擎**：原生多连接分片下载器（替代 aria2c.exe，参考 rclone/aria2 算法）
- **播放**：HTML5 网页播放器（MP4/WebM 原生解码，HLS.js/dash.js 按需加载，Go 本地会话代理隐藏上游签名）
- **持久化**：原子 JSON 文件存储（账号/设置/标签/收藏/任务/分享历史/同步任务）

### 在役 13 盘

pikpak · onedrive · dropbox · pan123 · lanzou · ilanzou · pan139 · pan189 ·
yike · aliopen · guangya · webdav · s3

（gofile、gdrive 已按需求移除；旧 Electron 工程封存于 `../Mnemo`，仅作参考）

### 功能

- 文件管理：目录树/列表/排序/批量操作/重命名/搜索/回收站/收藏/标签
- 传输：原生分片下载（断点续传/限速/多连接）、队列上传、任务中心、传输悬浮球
- PikPak 云离线
- 在线播放：画质切换、倍速、音量、字幕、截图、画中画、断点续播
- 跨盘迁移（server→stream 流式）
- 双向同步（push/pull/two-way）
- 分享：创建/历史；OAuth PKCE（OneDrive/Dropbox）、账密、Cookie、短信验证码登录
- 设置：主题/下载目录/代理/限速/续播

### 验证

- `wails dev` 可启动 ✅（WebView2 运行时）

### 已知边界

- 上传大文件走分片/会话（onedrive/dropbox/aliopen/pikpak/pan139/pan189/pan123）；
  单文件超 150MB 的 dropbox 走 upload session。
- PikPak 登录遇滑块验证码时需浏览器交互。
- 139/189 等国内盘的风控与验证码依赖账号环境，联调以实际账号为准。
- 浏览器解码边界：MP4/WebM/HLS/DASH 依赖 WebView 能力；MKV/AVI/WMV/FLV/RMVB 等不稳定容器提示下载，不再打包平台专用播放器引擎。

### 端到端验证（本机无外网凭据）

- `internal/e2e/TestWebDAVEndToEnd`：本地 WebDAV 服务器上跑通
  store→token resolver→ops 门面→webdav driver→HTTP 客户端的完整链路：
  列表/建目录/上传/下载URL取回内容/重命名/移动/复制/删除，全过。
- `internal/e2e/TestSegmentedDownload`：本地 Range 服务器下载 10MiB 文件，
  4 连接多分片，字节级校验收敛一致；.part/.state 清理与续传/单流回退均过。
