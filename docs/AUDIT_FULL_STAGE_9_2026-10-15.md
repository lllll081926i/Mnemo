# 全审计整改：阶段九

## 范围与实现

继续推进 M30 的播放器会话生命周期。沿用不透明本机 URL，不新增携带云端鉴权的前端参数。

- 本机 `/stream/<session-id>?t=<token>` 增加 `DELETE`。必须携带正确令牌，只允许释放根会话，不允许用子资源路径撤销。重复释放返回 204。
- 撤销会话时移除会话表记录、清除源和资源索引，并取消会话上下文。已有上游读取、索引探测、续签和续签等待者随之停止；迟到的成功续签不得重新激活会话。
- 会话过期清理与服务器退出复用撤销逻辑。服务器退出清空会话表，拒绝新的播放源注册。
- 独立 `preview-lease` 模块维护播放器持有的主源与字幕。切换文件、切换清晰度和关闭时释放不再使用的会话；乱序或关闭后的迟到回执立即释放；不会撤销仍由当前播放源使用的相同会话。
- 同名外挂字幕使用独立所有权集合，关闭后迟到的字幕回执也被释放。播放器关闭时显式停止并移除原生视频源，不只销毁自适应播放器。
- 释放请求仅接受带令牌的 `127.0.0.1` HTTP 根会话地址。不会向任意云端 URL、本地文件路由或分片 URL 发送 DELETE。使用 keepalive 和无凭据请求；释放失败不阻塞界面关闭，仍保留服务端过期清理。

## 自动化验证

- 预览包竞态测试重复三次通过。
- 覆盖错误令牌、错误资源层级、重复释放、释放后旧资源返回 410，以及撤销后源凭据和索引清理。
- 覆盖释放时取消活动续签、拒绝迟到成功回执、取消活动 HTTP 读取，以及连续 1024 次创建/释放后会话表不增长。
- 前端新增 7 项测试通过。其中 3 项实际挂载 PlayerPanel，覆盖清晰度乱序、关闭后迟到播放回执与迟到同名字幕；其余覆盖共享会话保留、去重、地址边界和失败隔离。
- 全量前端为 279 项通过、1 项既有登录文案断言不匹配。本阶段保留并行文案修改，不把该结果记录为全量通过。
- Go 全量测试、受影响包竞态、vet、后端编译与前端生产构建通过。未生成本地应用安装包。

## 边界

本阶段释放视频播放器及其字幕会话。图片、文本、音频和文档组件的所有权管理仍需接入；原生窗口被操作系统强制结束时不能保证浏览器 keepalive 完成。服务端仍保留空闲会话过期清理，未宣称所有预览类型的内存与真实解码行为已验收。
