# 迅雷网盘接入规范

首版范围保留为历史提案。2026-10-05 已扩展容量、回收站和分享能力，当前契约以 `THUNDER_QUOTA_TRASH_SHARE.md` 及 `docs/providers/thunder.md` 为准。

## 首版范围

- 插件 ID 为 `thunder`，与既有账号隔离；统一走 `drive.Driver` 和能力声明。
- 使用 OpenList `drivers/thunder` 的移动端协议作为接口参考，独立实现，不引入其代码或依赖。
- 登录区提供全宽等分的“密码登录 / 短信验证码登录”切换；只收手机号和当前方式的凭据。密码和短信验证码均不写入账号持久化。设备 ID 自动生成并复用，签名、验证码 Token、临时信任参数由应用处理，不要求用户抓包或手填。
- 密码登录先调用 `/xluser.core.login/v3/login`，再初始化验证并通过 `/v1/auth/signin/token` 获取可刷新的授权；原有 Refresh Token 会话继续兼容，但不再作为普通用户登录表单。
- 出现滑块或短信风控时，在隔离的迅雷官方验证窗口完成验证，回调后自动继续；不支持回调的页面提供“已完成验证，继续登录”，服务端再次核实验证结果，不凭按钮点击跳过验证。临时会话有时限、绑定账号和设备，取消/切盘清理，禁止无限登录重试。
- Windows 窗口在官方 `vertifyPhone.html` 顶层页面加载后调用 `XlCaptcha.init`，配置容器、面板样式与成功回调；不能仅导航到默认隐藏的页面，也不能强行显示未初始化的表单。内部图形验证 iframe 仍由官方 SDK 管理。
- 安全验证 URL 补齐应用、设备、语言和临时信任参数，保留服务端手机号与 `userID`；缺少账号标识时不得伪造。验证组件加载失败或必要参数缺失应给出可见提示。
- 短信验证成功返回的 `creditkey` 与滑块的 `captcha_token` 分开回传；更新当前登录尝试的信任参数后续办，不将临时信任参数持久化。
- 短信登录参考迅雷官方 2026-09-16 网页 SDK：`/v1/auth/verification` 使用 `target=ANY`、`usage=SIGN_IN` 与 `+86 手机号`，`/v1/auth/verification/verify` 校验后使用 `verification_token` 和验证码调用 `/v1/auth/signin`。不调用注册端点；未返回已注册账号时明确报错。移动端客户端身份沿用当前驱动，真实账号及服务端风控兼容性仍待验收。
- 短信发送和登录分别初始化对应操作的 Captcha Token；发送前验证完成只续办发送，不能错误提交登录。重发至少间隔 60 秒，切换方式或取消会话不能绕过该限制。限时会话绑定手机号、设备及登录方式，验证码校验授权仅存在内存。
- 支持分页浏览、文件详情、下载、网页播放、新建目录、重命名、移动、复制、移入回收站、云离线提交/分页查询/删除。
- 暂不支持上传、分享、搜索、回收站浏览/还原、永久删除、保险箱、远程设备空间和切换客户端身份；不得声明这些能力。

## 安全与失败处理

- API 地址固定为 `api-pan.xunlei.com/drive/v1` 和 `xluser-ssl.xunlei.com/v1`；代理复用 `netx`。
- 设备身份持久化且不在刷新时改变；会话沿用现有账号加密存储。
- 同账号请求串行更新会话，刷新后的 Token 在释放账号锁前保存；不同账号相互隔离。
- 请求最多刷新访问 Token 一次、换发 Captcha Token 一次，禁止无限重登或客户端身份自动切换。
- 429、验证码、套餐/文件权限错误不能自动视为账号失效；仅确认凭据无效时返回 `drive.AuthExpired`。
- 下载和播放只携带下载 UA，不把账号访问 Token 或 Captcha Token 转发给下载服务器。
- 分页循环、缺失任务/文件 ID、空下载链接、业务失败和异步文件操作均不得冒充成功。

## 验收

- 覆盖注册/前端元数据、登录表单、刷新轮换与持久化、账号隔离、验证码签名/有界重试、429/403、不规则数字大小、分页循环、文件操作及离线完整流程。
- `go test ./...`、相关 race 测试、`go vet ./...`、前端相关测试和编译检查。
- 不生成安装包或验证版。无真实迅雷凭据时，只能声明模拟协议测试通过，不能宣称真实账号已验收。
- 2026-10-04 验证页修复：使用当天官方 HTML、vendor.js 和 vertifyPhone.js，在无账号鉴权的 DOM 环境确认页面由隐藏变为可见、手机号与“获取验证码”按钮正常初始化，未发送短信；真实 WebView2 以隐藏窗口验证两种网盘回调。上述检查不等于真实手机号登录成功。
