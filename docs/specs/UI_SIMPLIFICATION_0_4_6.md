# v0.4.6 界面精简

- 保留用户已精简的文案。页面优先显示操作、结果与必要错误，不常驻展示实现细节。
- 登录默认显示必要字段。连接高级设置可展开；第三方凭据授权同意和人机验证保留。
- 二级弹窗默认只提供关闭按钮；预览保留窗口控制。表单优先聚焦输入，危险确认保留取消优先。
- 文件类型筛选使用直接名称，不引入额外工作模式概念。预览、播放器、相册筛选和文件操作保持可用。
- 诊断与平台限制按需展开，危险操作确认不得省略。
- 进度更新通过任务索引定位，收藏标记使用集合查询。保留刷新与事件合并规则，不改变传输协议。
- 验证重点为登录切换、弹窗焦点、任务更新与前端构建；云端执行完整发布检查。
