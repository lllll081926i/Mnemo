# v0.4.4 发布规范

## 范围

提交自 v0.4.3 以来的全部功能与修复，包含用户确认的光鸭图标尺寸调整。正式版本号为 v0.4.4，发布仓库为 `lllll081926i/Mnemo`。

## 发布门槛

- 全量 Go 测试、全量竞态检查、静态检查、格式检查与编译通过。
- 全量前端测试、生产构建、依赖检查与浏览器工作区验收通过。
- 应用、Wails 产品信息、前端清单、锁文件与安装器版本一致。
- 更新器和文档指向正式仓库；公开更新说明列明能力、已知限制与验收范围。
- 用户确认正式发布后推送代码与标签，由 GitHub Actions 构建五种平台架构。
- 14 个安装包/归档和校验文件完整后才公开草稿 Release；不得覆盖已公开版本。

## 边界

本地测试和云端构建不能证明所有网盘套餐、风控、第三方协议和真实文件均没有问题。不将未完成的迅雷上传、分享转存、所有网盘上传正文续传或迁移正文续传写成已支持。
