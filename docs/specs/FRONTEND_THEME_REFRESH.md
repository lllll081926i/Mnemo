# 前端主题与文件工作区换新

日期：2026-10-30。

## 需求

引入极简黑白、静谧纸感两种外观，各自支持浅色、深色和跟随系统。保留 OLED 选项。顶部导航显示文字，顶部搜索使用输入框。增加 demo 中的分栏浏览版式。校正图标与顶部返回区域分隔。目录树使用稳定自然排序。传输列表保持清楚的阶段与统一通知。调查并修复 123、两个蓝奏云、阿里网盘及其他回收站适配问题。

## 实施约束

- 沿用 Vue 3、现有组件和设计变量，不增加 UI 框架。主题偏好复用现有本地偏好与备份；独立文档预览同步外观，媒体保持沉浸式背景。
- 网盘文件列表保留选择、剪贴板、批量操作、双栏迁移、拖拽和虚拟化。新增分栏模式用于逐级浏览目录，不代替双栏跨盘工作区。
- 目录树与文件列表使用确定的名称比较，数字自然排序；目录树不随上传大小等文件排序条件跳动。
- 回收站按 provider 能力处理。不得将登录失效或未知响应显示成空回收站，不得将永久删除作为回收站删除。无法通过账号授权使用的接口要明确说明并提供官网入口。
- 保留原有用户文件 `docs/Mnemo审计报告.md`。

## 核验

运行相关组件和 provider 回归测试、完整前端测试与生产构建、Go 编译与测试。浏览器检查黑白与纸感的明暗主题、窄窗口、搜索、分栏浏览、长目录与错误恢复。最后更新 Windows 测试程序并记录验证边界。

## 实施结果

- 顶栏改为四个独立的图标与文字导航，共享细底线随当前页滑动；取消胶囊滑块。新增顶部搜索输入框，Enter 带入关键词打开全盘搜索。移除顶部“我的空间”入口；项目名与导航之间保留短竖线，搜索右侧不增加竖线。双栏工作区与目录分栏分别使用独立语义图标。
- 新增纸感和黑白两套变量，均支持明暗模式、系统跟随、OLED。实心按钮和危险按钮的前景色分别适配深浅背景。预览窗口读取打开时的主题，媒体保持黑场。
- 新增目录分栏组件，支持逐级导航、祖先目录切换、选择、右键和键盘焦点定位。万条目录使用虚拟列表。账号切换、清除缓存和目录失效时清除旧快照并重建。目录树和目录选择器使用自然排序。
- 顶栏高度收紧至 44px。面包屑移除返回按钮与竖线，仍支持祖先目录点击和 Backspace 返回上级。文件工具栏移除文件类型下拉框，依次显示新建、上传、刷新、搜索、云离线、选择；粘贴操作在剪贴板有内容时紧随上传。排序与版式放在右侧。按钮使用 26px 高度、淡描边与统一 6px 间距，工具栏与面包屑水平留白均为 8px。移除两行底部横线，目录树根部留白及逐层缩进同步收紧。
- 传输行调整文字、阶段和进度层级，窄窗口改为分行排版。内部错误码仍进入日志，错误详情使用统一通知。
- 123 回收站使用官网回收站参数与分页游标，兼容列表成功码 0/200，并拒绝缺失列表和重复分页。蓝奏优享兼容顶层及旧包装列表，普通蓝奏用 HTML 结构读取表单令牌，不再要求列表页含恢复令牌。两者均保留失败状态，不把异常当成空列表。
- 阿里 Open 不支持读取和恢复回收站，删除错误的原生网页登录接口回退，改为官网入口。123 与两个蓝奏云读取失败时也提供官网入口。其他 provider 运行现有能力与协议回归，未声称真实账号验收。

## 验证结果与边界

- 前端 39 个测试文件、315 项测试通过。生产构建通过，保留已有大型预览依赖分包体积提示。
- `go test ./...`、`go vet ./...`、`go build ./...` 通过。阿里、123、两个蓝奏云的 `go test -race` 通过。`gofmt -l .` 无输出。
- Edge 浏览器通过四种主题、系统明暗切换、顶部带词搜索、三层分栏、万条虚拟列表、祖先切换、账号切换、双栏工作区与备份恢复检查。标题栏宽度核验为 680、800、1024、1440 像素。设置另检查 1024/3840 宽度、100%/125%/150% 缩放、明暗/OLED、高对比度和减少动态效果。
- 连续文档滚动回归通过：PDF 30 页、PPT 12 张、表格 4000 行、Word 3 页。浏览器开发服务器出现 HMR WebSocket 网络限制提示，不影响文档加载与滚动断言。
- Windows 构建 `build/bin/Mnemo-review.exe` 成功。未连接真实账号执行回收站恢复、永久删除或上传写入。
