# PR 复核剩余缺陷整改

## 范围

按用户确认，处理复核记录中的实际缺陷，不扩展为原始审计全部 65 项功能。

1. 升级 Vue 补丁版本和 source-map-js，重新执行生产依赖审计。
2. 将离线展示 URL 脱敏下沉至存储边界，启动迁移旧记录；失败显式返回，不备份明文凭据。HTTP(S) 仅保留来源，避免路径内签名泄漏。
3. 为 WebDAV PUT 增加实际网络写入期限；本地读取与主动限速等待不计入网络写入期限。保留响应头超时和用户取消。
4. 禁止无账号作用域删除离线历史，避免误删其他账号同 ID 记录。

## 验证

添加旧数据迁移、重复迁移、读取/写入失败、作用域删除、网络写入阻塞、慢正文与取消测试；执行 Go 测试、竞态检查、前端测试及构建。真实网盘回执和第三方权限只能保留为待真实账号验收，不使用模拟测试冒充实测。
