# 登录页与二级弹窗布局

## 布局约束

- 网盘服务列表隐藏两个方向的滚动条；保留滚轮、触控和键盘滚动。
- 登录方式切换和表单字段使用同一内容宽度，两个登录方式等宽。
- 短信验证码按钮位于验证码输入框内，沿用主题色、焦点样式和发送倒计时。
- 通用弹窗和快捷命令面板的关闭按钮紧贴标题栏右上角。图片、音频和视频的自定义标题栏保留已有贴角布局。
- 内嵌人机验证使用左侧二级弹窗。Esc 只关闭最上层弹窗。
- Windows 原生验证窗口与应用窗口左边缘对齐，并限制在当前显示器工作区内；保留官方验证页面与回调协议。

## 核验入口

- `frontend/login-methods.browser.cjs`：明暗主题、桌面和窄窗口、输入宽度、短信按钮位置、隐藏滚动条及滚动、左侧验证和快捷命令关闭按钮。
- `frontend/workspace.browser.cjs`：设置 `QA_DIALOG_LAYOUT_ONLY=1`，检查账号自定义、账号信息、搜索、分享导入、同步编辑、同步预览和确认弹窗的右上角关闭按钮。
- `frontend/src/components/interaction.test.js`：嵌套验证弹窗的 Esc 隔离和关闭行为。
- `internal/captcha/window_windows_test.go`：窗口左对齐、负坐标副屏、小屏和最大化边框的工作区约束。

浏览器脚本仅使用本地测试数据，不访问真实账号或验证码服务。

## 本地结果（2026-10-05）

- 明暗主题下，1440、720、600 像素窗口的登录布局检查通过；7 个工作区二级弹窗的关闭按钮位置检查通过。
- 109 项相关交互测试通过。前端全量 240 项通过，1 项既有断言仍期待“纯文件夹不提供下载”；本轮不修改该无关断言。
- Go 全量测试、验证码与应用层竞态测试、静态检查、后端编译及前端生产构建通过。
- 不生成验证版或安装包。真实网盘人机验证仍需登录验收。
