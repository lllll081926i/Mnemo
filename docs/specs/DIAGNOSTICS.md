# 按需诊断

- 设置中的诊断中心默认只检查本机回调端口、下载目录临时写入和本机账号认证状态。
- 用户选择账号后只读根目录第一页。网盘可能自动刷新本次读取所需的凭据；不进行云端写入，不恢复任务。
- 公共网络检测须主动勾选，检查 DNS、TCP 与 GitHub 公共 HTTPS。公共端点成功不等于网盘端点成功；代理下本机 DNS 失败也不能单独判定代理失败。
- 请求总预算 25 秒，网络子步骤有独立上限。驱动须遵守现有 context 契约。
- Range、其他目录权限、套餐、OAuth 应用授权及云端写入没有执行时显示“未检测”，不以本机结果代替服务端验收。
- 导出使用后端生成的固定结构，不接收前端自填报告，不包含原始日志、账号标识、文件名、路径、令牌、代理地址或签名链接。

核验：本机统计、临时文件清理、缺失目录失败和敏感字段隔离使用一项定向回归。
