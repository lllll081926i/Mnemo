# 全审计整改：阶段八

## 范围

推进 M30 的 Go 媒体代理并发、取消与内存边界验收。本阶段不修改播放器界面，不覆盖正在并行调整的文案。

## 修复

- 续签网络请求不再持有会话数据锁。旧实现会阻塞资源读取，并在注册其他预览时连带阻塞全局会话表。
- 使用可取消的会话续签门控。等待者取消后立即退出，不必等待上一个网络请求完成。
- 为播放源增加后端内部版本。同一旧版本遭到并发 401/403 拒绝时，只执行一次成功续签；即使服务商只更换请求头而不更换 URL，也能正确识别新版本。
- 视频和字幕续签经 `GetVideoPreviewContext` 传递请求上下文，不再丢弃关闭预览时的取消信号。保留旧门面供现有调用方使用。
- 播放清单和字幕按解压后 8 MiB 限制读取。超限返回错误，不再将截断的 HLS、MPD 或字幕作为完整正文继续处理。

## 自动化证据

- 32 个并发工作者累计执行 4096 次源解析与 HLS/DASH 混合资源登记。过期源只续签一次，资源与反向索引保持一致，总索引不超过 2048 项。
- 阻塞续签期间，独立预览注册仍能完成；等待者和执行者均支持取消。
- 64 个并发旧回执只触发一次成功续签，覆盖 URL 不变、鉴权请求头变化的情况。
- 16 个并发 Range 读取取消后，上游 HTTP 请求全部收到取消并释放，不依赖强制关闭上游测试服务器。
- 8 MiB 边界与超限一字节均覆盖普通正文和 gzip 解压正文。
- 预览包竞态测试重复三次通过。Go 全量测试、全量竞态、vet、后端编译通过。
- `BenchmarkPlaybackResourceChurn` 在本机三次结果为 651.0～856.5 ns/op、288 B/op、9 allocs/op；只是本机资源登记基线，不代表真实视频吞吐或跨设备性能。
- 前端任务诊断专项 25 项通过。并行文案编辑期间，全量前端结果为 272 项通过、1 项旧文案断言不匹配；本阶段未改写登录文案或替用户调整该断言。

## 保留边界

未完成原生 WebView 的硬件解码、4K HDR 色彩、ASS 大动画、音轨切换和操作系统代理切换实测。没有将本机 HTTP 压力测试等同于这些验收。会话关闭接口、空闲会话的主动回收与更完整的前端生命周期矩阵仍需继续完善。
